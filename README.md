# Artistry Studio – Art Drawing Business Website

A modern, elegant, fully responsive website for an art drawing / fine art business.

## Live Demo
https://musyokidennis926-hub.github.io/art-drawing/

## Features
- Hero section with call-to-action
- About the artist with stats
- Portfolio gallery with category filters
- Services (Commissions, Originals, Prints)
- Commission process steps
- Contact form (demo)
- Fully responsive
- Dark elegant artistic theme

## Files
```
index.html    → Main page
styles.css    → All styles
script.js     → Interactivity
README.md
```

## How to Customize
1. Replace the placeholder image boxes with your real drawings
2. Update text, email, social links, and stats in `index.html`
3. Change colors in the CSS variables at the top of `styles.css`

## Contact Form
The form currently shows an alert. To make it real:
- Formspree: change the form action
- Netlify Forms: add `netlify` attribute
- EmailJS: use their SDK

## Deploy to GitHub Pages
Just upload these 3 files (`index.html`, `styles.css`, `script.js`) to your repository root and enable GitHub Pages.
